# Requisitos priorizados

1. Instalación local reproducible y acceso autenticado.
2. Cursos matriculados, calendario, tareas, entregas y calificaciones nativos.
3. Tema accesible y navegación móvil; datos reales filtrados por Moodle.
4. Datos ficticios y pruebas completas de docente y estudiante.
5. Solicitud/aprobación de aulas, comunicación institucional y reportes después del MVP.
6. Rendimiento medido en el entorno objetivo y protección de datos de menores.
