# Copias de seguridad

Se necesitan respaldos coordinados de PostgreSQL, Moodledata y configuración, protegidos y cifrados fuera del servidor. Antes de definir un procedimiento operativo, implementar modo mantenimiento, volcado consistente, copia de archivos y ensayo de restauración aislada; registrar resultados y retención aprobada. El entorno actual no proporciona todavía un comando de backup validado: no confiar en una copia improvisada para producción.
